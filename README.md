# HyMod
Multiversion mod for Hypixel adding features for bedwars (resource display), arcade, chat waypoints and more!

## Features

### Bedwars

#### Bedwars Resource Display
- Displays your iron, gold, diamonds and emeralds while in bedwars game
- Shows both inventory and ender chest
- Works with new ender chest punching feature


### Arcade

#### Farm Hunt
- Shows waypoint on dangerous taunt message


### Chat

#### White Chat Messages
- White private messages
- White no rank messages

#### Hide Guild MOTD
- Hides guild message of the day

#### MVP++ Emojis
- Replaces emojis like "<3" with "❤"

#### /sendcoords Command
- Usage: /sendcoords <all/party>
- Sends your coords to <all/party> chat

#### Coords Waypoints
- Shows waypoint on coords sent by you / other players
- Customizable color, beam opacity, box opacity and time to disappear
- Renders player nametag and distance to waypoint


### GUI

#### Middle Click GUI Items
- Replaces left click with middle click in GUIs
- Intended for overall Hypixel Network usage, use [Legacy Skyblock](https://modrinth.com/mod/legacyskyblock) for Hypixel Skyblock instead
